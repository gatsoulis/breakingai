# Do I need all that reasoning?

A personal investigation into how much reasoning effort a task needs—and whether additional accuracy justifies the extra token consumption and waiting time.

Through experiments with GPT-6 Luna on synthetic puzzles, the post compares reasoning settings and tests whether calculator assistance can achieve comparable results at lower effort. It examines the accuracy gains, remaining errors, and resource overhead of tool use.

This folder brings together the post and its supporting scripts, data, and results.
